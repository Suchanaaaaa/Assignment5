# Dev Stack — Development Stack Builder

A responsive React application for exploring development technologies and assembling a personal stack.

## Features
- Loads technology information from JSON.
- Add technologies without duplicate selections.
- Remove a single selection or clear the complete stack.
- Responsive navigation with a mobile menu.
- Loading and empty-data states.
- Toast notifications for stack actions.

## Built with
React, Vite, JavaScript, CSS, JSON and React-Toastify.

## Run locally
```bash
npm install
npm run dev
```
